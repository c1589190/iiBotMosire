# 决策解释（Decision Notes）

本目录记录**已经发生的重要取舍**及其理由，例如：

- 为什么选择事件驱动而不是状态表直写；
- 为什么外部 MCP 默认只读/回环；
- 为什么不用 AgentLib 的决策包表示玩家决策；
- 某次失败实验的结论与被取代方案。

## 规则

- 不是设计正本：设计以 `docs/superpowers/specs/**` 为准，维护以 `docs/agents/MAINTENANCE_RULINGS.md` 为准。
- 一条记录只讲一个决定，包含：背景、选项、决定、理由、影响、替代/后续、日期、相关证据。
- 被取代时移到 `archived/` 并在头部写取代者；不删除历史。
- 不复制长篇设计；需要时链接。

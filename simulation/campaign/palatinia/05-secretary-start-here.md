# 秘书开本检查单

> 本文件是秘书/GM 的内部检查单，不是发给玩家的文件。
> 当前个人本采用“世界固定、角色开放”的方式：只固定时代与局势，不固定玩家职位、关系和第一场戏。

## 一、会话开始前

秘书应先确认：

1. 已读取本工作区 `AGENTS.md`；
2. 已读取共享 Skill 中的帕拉丁秘书规则；
3. 已获得本玩家可见的世界资料与角色资料；
4. 不知道的内部事实不猜测，不把 GM 私有内容说给玩家；
5. 系统提示词保持最小，不把长篇规则塞回 system prompt。

## 二、第一次私聊

只发一段简短开场，不要求玩家阅读文件，不展示路径、版本或内部编号：

```text
《七柱之下：败退之后》个人本可以开始了。

这个世界是古比奥战败后的帕拉丁帝国西境。你只需要告诉我五项：
姓名、性别、年龄、职位、其他介绍。

其他介绍可以写出身、性格、经历、目标、关系、秘密，或者你希望开局关注什么；一句话也可以。职位不必从固定列表里选，按你想要的来。
```

如果玩家先问世界是什么，可以先用 2–4 句说明：

- 古比奥城下的败退被官方称作“善意撤退”；
- 西境刚进入战后第一个冬天；
- 军费、税册、欠饷、难民、神庙与元老院调查同时压来；
- 玩家将作为一名能接触具体事务的帝国基层人员进入这个世界。

然后回到五项信息。

## 三、收到五项信息后

1. 用玩家原话整理，不擅自补写秘密、目标、资源或政治立场。
2. 把“其他介绍”视为玩家自定义的核心内容，优先保留其意图。
3. 对职位做世界相容性检查；若需调整，先说明并给最小改动方案。
4. 将报名记录以 PRIVATE 方式交给 GM；不发布、不发群。
5. 只告诉玩家：“已经记下。我先按你给的信息准备开局，之后随时可以改。”

不要要求玩家确认报名、补全长表、提供 QQ 或选择活跃时段。

## 四、GM 准备角色与开局

GM 应基于玩家五项信息，准备：

- 角色卡：身份、职位、辖区/部队、权限、资源、限制；
- 世界位置：当前所在城市、岗位与局势；
- 已知事实与未知事实；
- 2–3 个自然行动方向；
- 玩家可自由补充的留白。

不得把开局写成固定剧本，也不得替玩家决定第一项行动。

## 五、开本前检查

- [ ] 角色姓名、性别、年龄、职位与介绍均来自玩家或经玩家同意；
- [ ] 职位与帕拉丁帝国行政、军事或社会逻辑相容；
- [ ] 没有把职位硬塞进预设模板；
- [ ] 没有给玩家强塞秘密、私人目标或政治立场；
- [ ] 玩家知道“我在哪、发生了什么、我有什么、我能做什么”；
- [ ] 没有暴露其他玩家、GM 私有事实或内部编号；
- [ ] 没有把系统说明、测试、自动监控、回合状态写进玩家可见文本；
- [ ] 真实出站前已获得真人 GM 明确确认。

## 六、正式行动

只有进入正式行动后，才使用唯一一次硬确认：

```text
发送 /确认 <短确认码> 即可提交。
```

确认码必须来自宿主工具返回值，不得编造。玩家确认后只回“已确认，交给 GM 处理”，不得再次索要确认。

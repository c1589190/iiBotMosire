# 《七柱之下：败退之后》

> 帕拉丁帝国，古比奥—帕拉丁战争战败后的国内政治—军事推演。
> 状态：已开本。世界事实已加载，9 名玩家与 9 个秘书工作区已初始化。

## 本轮故事

- 时间：帕拉丁历 501 年 11 月（通行历 1445 年 11 月）。
- 地点：以帝国西境新行省为核心，连接首都图拉真努斯城、卡普亚通道与北方矿区。
- 玩家：帕拉丁帝国内的地方官、中央基层官员、基层军队军官。
- 基调：低魔、硬政治、强财政约束、军事后勤写实；不是单人英雄史诗。
- 核心问题：古比奥前线没有输掉帝国，却输掉了“帝国不可战胜”的政治信用。战败真相、军费、行省编户、元老院、七柱神庙、军团欠饷和火器改革同时压到基层。

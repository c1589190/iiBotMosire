# 秘书报名接收规范 v2

本规范替代 `gm/registration-protocol.md` 中关于“六位确认码 / 推文+二次确认”的规则。

1. 报名表已直接下发到 `player/registration-form.md`。
2. 玩家填写后私聊秘书；秘书必须检查缺项、矛盾和越权内容，缺失项直接追问。
3. 不再要求确认码，不再要求玩家二次确认。
4. 检查完成后，秘书直接调用 `secretary_post_create` 创建 `PRIVATE` 报名推文：
   - 标题：`帕拉丁报名｜<称呼>｜<QQ后四位>`
   - 正文：完整报名表整理稿
   - `expectedRevision`：当前玩家草稿集合 revision
   - `idempotencyKey`：每个玩家每版唯一
5. 创建后只向玩家报告 `postId`、`status`、`revision`，并说明“已提交 GM 审核”。
6. 不得批准、发布、公开、群发或声称已被录取。
7. GM 审核后会下发正式角色卡、世界资料摘要和开局任务；在此之前，玩家可以继续补问，但不得执行正式军事、征税或司法行动。
8. 旧规范中与 v2 冲突的部分一律作废。

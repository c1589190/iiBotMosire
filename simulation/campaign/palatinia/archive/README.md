# 历史文档归档

本目录保存《七柱之下：败退之后》在 2026-10-24 之前的报名、通知与秘书流程版本。

这些文件只用于追溯，不是当前操作规范。当前正本见上级目录的 `README.md`。

## 归档原因

- 旧版报名曾要求六位确认码、二次确认或 QQ 后四位；
- 旧通知曾要求玩家阅读工作区文件；
- 同一流程存在 v1、v2、v3 多套互相冲突的版本；
- 旧版把玩家职位、长表和流程状态定得过细，不符合当前个人本“世界固定、角色开放、只收五项信息”的方向。

## 使用边界

- 不得让秘书按归档文件执行报名或确认流程。
- 不得从归档文件推断当前 runtime 状态、玩家数量或开本状态。
- 不得把归档中的玩家可见文案直接发给玩家。
- 若需恢复某条旧规则，先把它合并进当前正本，并在 `CURRENT_STATE.md` 记录变更。

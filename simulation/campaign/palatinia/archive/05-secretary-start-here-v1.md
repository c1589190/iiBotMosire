# 《七柱之下：败退之后》开本通知

本战役已开本。你的秘书工作区现在包含：

- `player/world-basics.md`：本局世界、帝国、西境局势与角色范围。
- `player/registration-form.md`：玩家报名表。
- `gm/registration-protocol.md`：秘书接收报名的内部规范。

请玩家先阅读 `world-basics.md`，填写 `registration-form.md`，然后把完整报名表私聊发给本秘书。

秘书收到后：

1. 检查缺项、矛盾和越权内容；
2. 把整理后的报名稿回给玩家确认；
3. 玩家精确回复确认后，才创建 `PRIVATE` 报名推文；
4. 报名推文进入 GM 审核，不公开、不直接发送到群里。

在 GM 下发正式角色卡和开局任务之前，玩家可以继续完善报名、询问世界常识和表达剧情偏好，但暂不执行军队调动、征税、逮捕或其他会改变世界状态的正式行动。

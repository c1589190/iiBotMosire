# 开本报名最新流程

1. 报名表已在你的秘书工作区：`player/registration-form.md`。
2. 玩家填写后直接私聊秘书。
3. 秘书检查缺项、矛盾和越权内容，必要时向玩家追问。
4. 检查完成后，秘书直接把整理版报名表创建为 `PRIVATE` 报名推文，提交 GM 审核。
5. 不再要求六位确认码，不再要求二次确认，不再要求玩家另行发一条确认消息。
6. 报名推文不公开、不发布、不发送到群里。
7. GM 审核并初始化角色卡、工作区和开局任务后，玩家才会收到正式角色信息。

秘书创建报名推文时使用：

- `visibility=PRIVATE`
- 标题：`帕拉丁报名｜<称呼>｜<QQ后四位>`
- 正文：完整报名表整理稿
- `expectedRevision`：使用当前玩家草稿集合 revision
- `idempotencyKey`：每个玩家每版唯一

创建后只报告 `postId`、`status`、`revision`；不得批准、发布或声称已录取。

# 05 发布模板

## 公开推文

```text
【地点｜世界内日期】

一个具体场景或公开事件。

一个公开可感知的后果。

一个下一步钩子。
```

规则：

- 只写世界内事实；
- 不写“第 X 回合/第 X 日”这种系统时钟（除非产品明确把回合名作为世界内制度）；
- 不写“这是自动/测试/不预设结果”；
- 不写 GM 刚刚没做什么；
- 不混入规则说明、报名表或后台状态；
- 一条只讲一个事件；
- 不泄露私密玩家行动原文。

## 私密结果

```text
【本旬结果｜角色名】

你已经做的事情：
...

已经发生：
...

你新增知道的信息：
...

你的资源/位置/关系变化：
...

仍未确定：
...

下一步你可以：
A. ...
B. ...
C. ...
```

## 报名回执

```text
已经记下。你的暂定身份是：...
我先按这个方向准备开局；之后任意一句话都可以改。
```

## 公告

公告与叙事分开。公告只写规则/时间/操作信息，必须明确是系统公告，不伪装成剧情。

# 04 信息卡

## 玩法卡（首次）

```text
《七柱之下：败退之后》个人本可以开始了。

这个世界是古比奥战败后的帕拉丁帝国西境。你只需要告诉我五项：
姓名、性别、年龄、职位、其他介绍。

其他介绍可以写出身、性格、经历、目标、关系、秘密，或者你希望开局关注什么；一句话也可以。职位不必从固定列表里选，按你想要的来。
```

## 开局卡

```text
【开局卡｜角色名】
你现在在哪里：...
你面前正在发生：...
你知道的三件事：
1. ...
2. ...
3. ...
你手里有：...
你的限制：...
你现在可以：
A. ...
B. ...
C. ...
也可以直接说自己的做法。
```

## 信息答复卡

```text
直接回答：...
补充背景：...
你现在可以：
A. ...
B. ...
C. ...
```

## 结果卡

```text
【本旬结果｜地点/日期】

已经发生：
...

你知道了什么：
...

你的变化：
...

仍未确定：
...

下一步你可以：
A. ...
B. ...
C. ...
```

## 错误卡

```text
【系统】
刚才消息没有正常处理/送达。
你已提交的行动仍然保留/未保留。
请直接回复：...
```

## 规则

- 优先发当前决策所需信息，其余展开按需；
- 不把文件路径当时信息；
- 一次不超过 3 个选项；
- 每张卡只讲一个焦点。

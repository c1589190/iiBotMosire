# 00 体验总纲

## 一句话目标

玩家用自然语言说出想做的事，就能在**一次确认内**正式提交；玩家问任何当前局势问题，都能在**一条聊天回复内**知道发生了什么、自己知道什么、下一步能做什么。

## 玩家不需要知道

- draftId / ticketId / postId / revision / contentHash / turnId；
- MCP / schema / payload / workspace / 文件路径；
- 报名表版本、start-here 版本、确认码历史；
- 哪个模块拥有哪个状态。

## 玩家应该始终知道

1. 我是谁、在哪里；
2. 眼前发生了什么；
3. 我已经知道什么、还缺什么；
4. 我现在能做的 2–3 个具体方向；
5. 我刚才的行动是否已经记下来；
6. 下一步何时、以什么方式得到反馈。

## 成功标准

- 新玩家第一条私聊后就知道如何提供角色信息并进入开局；
- 普通行动 ≤ 2 条玩家消息完成（自然语言 + 一次确认）；
- 没有玩家被要求阅读工作区文件；
- 没有因缺项、版本或内部 ID 形成的死胡同；
- 不出现后台状态、Markdown、推理链或测试/自测消息；
- 每条结果先给事实，再给未知，最后给行动。

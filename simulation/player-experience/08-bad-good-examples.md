# 08 正反例

## 反例：程序状态

```text
draftId: ecfc67d7-...
PENDING_APPROVAL revision 1
请发送 /确认 ecfc67d7-...
```

问题：后台 ID、状态枚举、确认信息重复且不可读。

改写：

```text
我已经按“先查车队文书，再向财务使请示”的方向整理好了。
如果按此执行，发送 /确认 K7Q2M9。
```

## 反例：文件路径

```text
请阅读 player/registration-form-v2.md 后完成报名。
```

问题：QQ 玩家没有工作区。

改写：

```text
报名只需先告诉我三件事：称呼、想当什么身份、最想先玩什么。
其他我先替你暂定。
```

## 反例：反复确认

```text
请确认角色卡。
请确认报名。
请确认行动草稿。
请再次发送 /确认。
```

问题：玩家已经提交仍在被追问。

改写：

```text
角色方向我已经记下，先按这个开局；之后一句话就能改。
```

## 反例：无重点的公共推文

```text
系统说明：自动链路测试产物。第2回合第4日。GM刚刚没有做……
```

改写：

```text
【卡普亚北隘｜11月4日】
冬雨里，税关前积起三支车队。守门书吏开始逐车抄录封条。
商队今天仍不能通行，但至少知道该找谁补文书。
```

## 反例：条件句堆砌

```text
你可能可以执行，但可能受阻，部分待定，存在风险，后续可能……
```

改写：

```text
可以执行的部分：你已扣下车队并开具查验记录。
仍不确定：军需官是否补印。
下一步：A 等上级回复；B 约见军需官；C 先放行非军需货。
```

# 联系人：康斯坦丁

## 上级与同僚

- **卢基乌斯·奥菲迪乌斯·保卢斯**：西境行省财务使，骑士出身，你的旧上司。赏识你的账目能力，但把你放在卡普亚也是为了盯住隘口。近期将派审计官。
- **提图斯·卡尔维乌斯**：关卡验货书吏，年轻、精明、知道副册窟窿。可提拔，也可能成为威胁。
- **塞普蒂米乌斯**：另一名验货书吏，老实但反应慢，家中人口多，容易被收买或被恐吓。

## 地方势力

- **马尔库斯·维比乌斯**：卡普亚驻军军需官，掌冬营补给。与特尔尼商人议会有往来，可能牵涉本轮可疑车队。
- **特尔尼商人议会**：要求尊重旧通行凭证，背后有粮商、船主和包税人网络。
- **卡普亚旧伯爵家残余管家**：仍掌握地方佃户与仓储关系，表面臣服帝国。
- **关卡附近酒馆老板**：消息灵通，愿意用酒钱换消息。

## 私人关系

- **昆图斯**：你的弟弟，在军团中服役。退伍后想回卡普亚；你打算用积攒的钱给他盘一处货栈。
- **知情书吏**：知道你的旧抽成。你尚未确认他想要钱、升职，还是想摆脱你的控制。

## 可接触的外部角色
